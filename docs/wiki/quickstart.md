## 安装

当前工程使用 Minecraft 26.2、Java 25、Fabric Loader 0.19.3、Fabric API 0.159.0+26.2，并使用 GeckoLib 5.5.5 的模型动画接口。请使用对应版本依赖，客户端与服务器使用同一模组构建。Snakes Alive 是可选软联动，不是开局必须安装。

把模组和运行所需依赖放进游戏/服务器的 `mods`，启动后生成 `config/corpseorigin.json`。修改服务端玩法配置后重启服务器；器官包另有界面刷新入口。升级前备份存档和配置。

## 默认按键

| 按键 | 用途 |
|---|---|
| V | 技能环，每页最多 10 个技能 |
| B | 技能树与学习 |
| 1 / 2 / 3 | 三个快捷技能槽；可能与原版物品栏键冲突，可改键 |
| H | 开关 HUD |
| F9 | HUD 设置 |
| F8 | 进化器官装配、3D 预览、进化天梯 |
| G | 已装配器官的吞吐能力 |
| 潜行 + G | 补充水、泥或沙储量 |

可在游戏控制设置中更改。快捷技能槽的绑定以技能界面提示为准。

## 两条起步路线

**自由成长**：凡人或普通尸兄通过击杀、探索、村民训练/配置传承、吸食血肉积累点数和机遇，再到 B 学习。并非每次机遇都直接获得已学技能；发现后通常还要满足等级、点数和前置条件。器官走 F8 的独立天梯。

**命名角色**：使用角色选择书，选择服务器允许的身份。创造物品栏有通用书和绑定角色的书；当前配方表没有角色书合成，生存发放方式由服务器安排。龙右、小金刚等有自带技能，其他技能按各自条件解锁。不要把切角色作为保留原角色全部技能的途径。

建议先查看 HUD 分清内力、气血、感染和饥饿；学会技能后再检查持物和形态。角色外观变化不代表额外资源已补满。
