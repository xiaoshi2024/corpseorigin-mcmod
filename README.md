# CorpseOrigin

**An unofficial fan-made mod based on *Shen Xiong* (尸兄 / Zombie Brother).**

The Seven-Star Coffin turns water into Corpse Water, infecting creatures through **Carrier → Onset → Lesion → Transformation**. Corpse Brothers evolve by killing and cannibalizing, choosing between **Qi Cultivation** or **Body Forging**.

This is a fan-made mod inspired by the original work.

---

## Features

- **Infection System**: Corpse Water corrupts water sources; creatures mutate through multiple stages
- **Dynamic Evolution**: Mutations based on attributes, actions, and kill count; unlock Elite units
- **Long You Boss Fight**: Multi-stage combat, minion management, Corpse Domain infection field
- **42 Characters**: Bai Xiaofei, Hei Xiaofei, Long You, Xiao Jingang, Zuo Hufa, Zhao Ritian, and more
- **103 Skills**: Nine Levels of Tiangang Qi, Ancient Poetry Sword, Seven Gourd Techniques, Killing Incarnation, and more
- **Organ Evolution & Assembly**: Custom GEO models, animations, full-body replacement, 3D preview, unlock ladder, attribute points, specialization choices
- **First Organ Traits**: Water Absorption & Storage, Water Gun Spray
- **Xiao Jingang's Gourd**: Attach / detach, devour, fire sea, acid spray, giant arms
- **Skin System**: `/summonzb <player_name>`

## Installation

**Requirements:** Minecraft 26.2 · Java 25 · Fabric Loader 0.19.3 · Fabric API 0.159.0+26.2 · GeckoLib 5.5.5

1. Install Fabric
2. Place Fabric API, GeckoLib, and CorpseOrigin into `mods`
3. Launch to generate `config/corpseorigin.json`
4. Client and server must use the same build

## Current Status

Core infection, mutation framework, evolution, Long You boss fight, 42 characters, 103 skills, organ system, organ packs, gourd system, paginated skill ring, internal force / qi-blood consumption, server config and commands are already in the mod.

Some character moves and systems are still being worked on, including Gui Gun and Black/White Generals' moves, Five Elements Metal/Water/Earth independent skills, Ground Burrow, multi-head camera, and script abilities. Shu Mountain, Hell's Gate, Immortal Master, and other elements are planned for future updates.

**Known Limitations:** Currently only Villagers have a unique mutation; all other creatures mutate into the same basic type. Organ ZIPs only sync definitions and body data, not models. Full-body replacement does not change hitbox or first-person view.
