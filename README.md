# Corpse Origin: 生物系统设计

## 核心循环

本模组生物系统以**感染-变异-进化**为核心循环：生物接触尸水后进入携带/发病/变异三阶段，变异时根据生前属性与执念转化为特定形态，击杀吞噬积累进化点解锁能力树，最终可晋升为拥有多阶段战斗机制的首领实体；同时支持群体智能、稀有突变、生态竞争等 emergent 玩法，龙右作为机制集大成者提供终极模板。

## 一、感染系统

### 触发事件
玩家找到龙右的棺材后，若不慎将其**丢入/放置于水中**，棺材将缓慢释放尸兄病毒。若无人干预，水源将在**32格范围内**完全转化为尸水。

**当前实现**：
- 棺材放置水中 → 32格范围内水被感染
- 棺材移除 → 仅在海洋中（16x16范围内水方块>100）清除感染
- 棺材检测周围尸兄（8格半径）→ 触发召唤和动画

### 感染途径
| 方式 | 条件 | 感染值增长 |
|-----|------|-----------|
| 直接接触 | 生物处于尸水方块中 | 每500ms检查一次 |
| 饮用 | 生物尝试饮用尸水 | 暂未实现 |
| 伤口渗透 | 生物生命值&lt;50%时接触 | 暂未实现 |
| 母体传播 | 感染母体繁殖 | 暂未实现 |

### 感染阶段
| 阶段 | 持续时间 | 表现 | 可逆性 |
|-----|--------|------|--------|
| 携带期 | 持续接触 | 无外观变化，可传播病毒 | ✓ 血清治愈 |
| 发病期 | 中毒效果持续 | 皮肤苍白，咳嗽，移速-10% | ✓ 高级血清 |
| 病变期 | 持续中毒 | 血管凸起，攻击欲望+，拒绝正常食物 | △ 治愈后虚弱 |
| 转化期 | 效果持续20tick | **触发变异**，实体替换为尸兄 | ✗ 不可逆 |

### 转化规则
转化时读取原实体数据：
- **基础属性**（生命/攻击/速度）→ 决定尸兄强度基准
- **最后行为**（进食/战斗/逃跑/保护）→ 决定变异方向
- **击杀记录** → 高击杀数生成复仇型/猎手型

**当前实现**：
- 玩家接触尸水 → 获得中毒效果（60tick，每3秒一次）
- 村民接触尸水 → 获得 BYeffect 效果（3-15秒随机延迟触发变异为尸兄）
- 其他生物接触尸水 → 获得 BYeffect 效果（3-15秒随机延迟触发变异）
- 尸兄攻击村民 → 15%概率感染村民（使用 BYeffect）
- 龙右智能判断 → 15%概率感染村民，85%概率作为食物
- 龙右智能评估玩家价值 → 20-40%概率感染玩家，其余作为食物

**变异规则**：
- **村民** → 尸兄（LowerLevelZbEntity），30%概率为裂口变种
- **玩家** → 尸族玩家（获得技能系统）
- **其他生物**：暂未实现变异

### 感染源追踪系统
- 记录感染者UUID → 感染源UUID的映射
- 用于建立尸王与手下尸兄的主从关系
- 尸王可以感知到自己感染转化的尸兄

## 二、变异系统

### 典型行为事件
变异后的尸兄会表现出三种核心冲动，玩家可通过观察判断威胁等级：

#### 1. 暴食冲动
- **音效**：攻击时发出咀嚼/吞咽声
- **行为**：优先攻击可食用生物，击杀后停顿进食（3秒硬直）
- **特殊**：进食时回复20%生命值，可被打断

#### 2. 循声狩猎
- **触发**：玩家/生物制造噪音（挖掘、奔跑、攻击）
- **范围**：低阶15格 / 高阶40格 / 首领全图感知
- **机制**：噪音越大，尸兄移速加成越高（最高+50%）

#### 3. 同类相食
- **条件**：低阶尸兄（饥饿度≤20）相遇，且附近无尸王（32格范围内无等级5尸兄）
- **概率**：30%触发内战，胜者吞噬败者
- **结果**：胜者立即获得败者进化收益，可能触发**紧急进化**

### 恐怖表现库
变异尸兄随机获得1-3种外观特征：
- **表皮**：溃烂/角质化/透明化可见内脏/多眼增生
- **肢体**：关节反转/额外附肢/骨骼外露/触手替代
- **行为**：头颅180度转动/爬行移动/关节反折奔跑/无下颌嚎叫

### 尸兄变种系统
- **普通尸兄**：基础形态
- **裂口尸兄**：30%概率生成，攻击带定身效果
- **翅膀尸兄**：击杀鸟类后30%概率获得，可飞行
- **裂口翅膀尸兄**：裂口尸兄击杀鸟类后30%概率获得

### 尸兄器官系统
- **翅膀**：击杀鸟类后30%概率获得，可飞行
- **鱼尾**：击杀鱼类后30%概率获得

## 三、进化系统

### 两大路线

结合原作**炎黄武道**与**尸兄肉体进化**设定：

#### 路线A：修气（武道/异能）
&gt; *"以气御力，破而后立"*

| 阶段 | 名称 | 特征 | 解锁能力 |
|-----|------|------|--------|
| 地级 | 气感 | 体表微光，攻击带气流 | 气劲外放（远程普攻） |
| 天级 | 化形 | 气凝为武器/护甲 | 气罡护体（伤害减免） |
| 神级 | 领域 | 周身气压扭曲空间 | 气场压制（范围内敌方弱化） |
| 超神 | 归元 | 与天地共鸣 | 天地一击（蓄力全屏伤害） |

**获取方式**：
- 吞噬武者型尸兄/人类强者
- 修炼特殊功法物品（如《炎黄诀》）
- 龙右亲自"赐血"（剧情事件）

#### 路线B：修肉身（吞噬/变异）
&gt; *"弱肉强食，适者生存"*

| 阶段 | 名称 | 特征 | 解锁能力 |
|-----|------|------|--------|
| 地级 | 硬化 | 皮肤角质/骨甲覆盖 | 伤害减免，反伤 |
| 天级 | 再生 | 伤口快速愈合，断肢重生 | 战斗回血，复活一次 |
| 神级 | 异化 | 多器官/多形态切换 | 根据敌人切换抗性 |
| 超神 | 不死 | 细胞级再生，概念性存活 | 需特殊手段封印 |

**获取方式**：
- 大量吞噬生物（数量/质量均计算）
- 承受极端环境（熔岩/深海/真空）
- 被高阶尸兄击败后"放生"（残血逃跑后变异）

### 路线交织
- **单修**：专注一条路线，进阶快，弱点明显（气修怕近身/体修怕控制）
- **双修**：两条路线均投资，平衡但难以达到超神
- **变异**：特殊事件可转换路线（如气修被吞噬后转为体修保留部分能力）

### 当前实现
- 尸兄进化等级系统（1-5级）
- 击杀计数和进化点积累
- 进化时属性提升（生命值、攻击力、移动速度）
- 同类相食机制（30%概率触发）
- 尸兄视力系统（随等级提升而增强）
- 尸兄开门系统（进化等级≥3可开门，≥4可破门）

## 四、首领晋升

### 晋升条件
满足以下任一条件，普通尸兄进化为**首领级**：

| 条件 | 说明 |
|-----|------|
| 进化点≥1000 | 纯吞噬积累 |
| 击杀玩家≥3次 | 同一名玩家或不同玩家均可 |
| 吞噬特殊个体 | 命名生物/稀有变种/其他首领 |
| 剧情触发 | 龙右点名/特定地点觉醒 |

### 首领模板
- **多阶段**：至少2个战斗阶段，血量阈值触发
- **场地互动**：利用环境机制，改变战斗区域
- **召唤能力**：可召唤低阶尸兄协助
- **掉落专属**：首领级材料，制作顶级装备

### 当前实现
- 龙右实体（最终boss）
- 龙右智能系统（手下/粮仓区分）
- 龙右属性增强（500生命值，15攻击力，10护甲）
- 龙右气场技能（远程攻击防御，震飞攻击者，破坏武器）
- 龙右智能评估系统（评估尸兄和村民价值）

## 五、特殊机制

### 群体智能
- **信息素通讯**：尸兄通过气味标记共享敌人位置
- **分工协作**：大型尸潮中自动出现前锋/投掷/治疗角色
- **统帅链接**：首领存在时，范围内尸兄获得战术加成

### 稀有突变
- **环境适应**：极端环境生成的尸兄获得对应元素能力
- **命名个体**：满足隐藏条件生成的唯一尸兄，死亡不刷新

### 生态竞争
- **种内捕食**：高阶吞噬低阶，加速进化
- **领地意识**：首领级尸兄划定领地，入侵者必战
- **进化军备**：玩家越强，生成的尸兄平均等级越高

### 当前实现
- 振动系统（感知环境噪音）
- 饥饿度系统（控制同类相食）
- 尸王领导机制（32格范围内等级5尸兄抑制同类相食）
- 尸兄命令系统（跟随、攻击、防御、停留）
- 尸兄主人系统（被尸王收服后）
- 尸兄飞行系统（有翅膀的尸兄可飞行）

## 七、尸族特性系统

所有尸族实体（尸兄、尸兄鱼、龙右、尸族玩家）共享以下核心特性：

### 1. 被动生命恢复
- **机制**：每10秒自动恢复生命值
- **恢复量**：基础0.5 + (进化等级 × 0.3)
- **示例**：
  - 1级尸兄：每10秒恢复0.8生命值
  - 5级尸兄：每10秒恢复2.0生命值

### 2. 攻击回血机制（吞噬活物）
- **触发条件**：攻击任何活物（动物、村民、玩家等）
- **恢复效果**：
  - 饥饿度：+5
  - 生命值：1.0 + (进化等级 × 0.5)
- **说明**：尸族通过攻击和吞噬活物来维持生命力和饥饿度

### 3. 免疫毒素
- **免疫效果**：
  - 中毒（Poison）
  - 饥饿（Hunger）
  - 凋零（Wither，仅限龙右）
  - 所有有害效果（HARMFUL）
- **说明**：作为不死族，尸族对普通毒素完全免疫

### 4. 同类识别系统
- **不攻击对象**：
  - 龙右（尸王，绝对服从）
  - 尸兄玩家（同类）
- **例外情况**（会攻击同类）：
  - **被攻击反击**：被攻击后10秒内会反击
  - **极度饥饿**：饥饿度 ≤ 20 时会同类相食
  - **无尸王领导**：32格范围内没有等级5尸兄时

### 5. 饥饿度系统
- **范围**：0-100
- **消耗**：每5秒减少1点
- **影响**：
  - 饥饿度 ≤ 20：会攻击同类（同类相食）
  - 饥饿度 = 0：可能进入狂暴状态（待实现）

### 6. 尸族玩家特殊加成

| 进化等级 | 加成效果 |
|---------|---------|
| 1-2级 | 基础生命恢复、攻击回血、免疫毒素 |
| 3-4级 | 力量 I + 夜视能力 |
| 5级 | 力量 II + 夜视能力 |

### 7. 尸族玩家技能系统
- **技能树**：按等级解锁不同技能
- **技能类型**：被动技能、主动技能、持续技能
- **技能效果**：硬化皮肤、利爪、吞噬强化、进化感知、巨力、疾行、再生、毒液、狂暴、重击、跳跃、闪避、恐惧光环、不死之身、尸王之力、影袭、伪装
- **技能轮盘**：按R键打开技能轮盘，快速激活技能
- **技能界面**：按K键打开技能树界面，管理技能

- ✅ 尸族玩家转化系统

  - **多阶段战斗机制**：血量阈值触发不同战斗阶段，每阶段解锁新能力

## 十二、生存玩法指南

### 开局抉择：人类防线 vs 尸族进化

#### 🛡️ 人类阵营：生存与净化
> *"在尸潮中守护最后的火种"*

**核心目标**：保护村民、净化水源、阻止病毒扩散、最终击败龙右

**生存策略**：

| 阶段 | 目标 | 关键行动 |
|-----|------|---------|
| 初期 | 建立安全区 | 远离水源、加固基地、收集物资 |
| 中期 | 调查线索 | 寻找七星棺位置、研究血清配方 |
| 后期 | 组织反击 | 组建防御工事、净化感染源、挑战龙右 |

**关键玩法**：
- **水源监控**：定期检查附近水源是否被污染，及时封锁感染区域
- **村民保护**：建造防护屏障，训练村民自卫，防止尸兄入侵
- **血清研发**：收集尸兄样本，调配不同等级的治愈血清
- **武器锻造**：利用尸兄掉落的特殊材料打造克制尸族的武器

**危险时刻**：
- 夜晚尸兄活动频繁，需保持警戒
- 避免制造噪音，吸引循声狩猎的尸兄
- 受伤时远离水源，防止伤口渗透感染

---

#### 👹 尸族阵营：吞噬与进化
> *"在黑暗中蜕变，成为新的主宰"*

**核心目标**：感染更多生物、吞噬进化、挑战龙右夺取统治权

**生存策略**：

| 阶段 | 目标 | 关键行动 |
|-----|------|---------|
| 初期 | 适应新生 | 学习尸族特性、寻找食物来源 |
| 中期 | 建立势力 | 感染村民扩充手下、积累进化点 |
| 后期 | 挑战权威 | 吞噬高阶尸兄、最终对决龙右 |

**关键玩法**：
- **感染扩张**：主动接触水源加速变异，攻击生物传播病毒
- **吞噬进化**：优先击杀高价值目标快速积累进化点
- **手下管理**：收服低阶尸兄作为爪牙，组建尸潮军队
- **路线选择**：专注修气追求爆发，或专修肉身追求生存

**特殊能力**：
- **夜视能力**：3级解锁，黑暗中清晰视物
- **力量加成**：3级力量I，5级力量II
- **技能系统**：按R键打开技能轮盘释放特殊能力
- **同类相食**：极度饥饿时可吞噬同类快速恢复

---

### 生态互动：动态平衡系统

#### 🌊 尸水扩散机制
- **感染范围**：初始32格，随时间缓慢扩张
- **净化难度**：海洋中需清除16x16范围内超过100个水方块
- **连锁反应**：污染的水源会持续感染途经的生物

#### 🔊 噪音管理系统
- **声音来源**：挖掘、奔跑、攻击、放置方块
- **吸引范围**：低阶尸兄15格，高阶40格，龙右全图感知
- **应对策略**：夜间潜行移动，使用静音工具，建造隔音屏障

#### 🍖 饥饿循环
- **消耗速率**：每5秒减少1点饥饿度
- **危险阈值**：≤20时可能攻击同类
- **补给方式**：攻击活物恢复饥饿度和生命值

---

### 进阶玩法：挑战与机遇

#### 🏰 基地攻防战
- **尸兄破门**：进化等级≥3的尸兄可开门，≥4可破门
- **防御工事**：建造多层防线、陷阱、瞭望塔
- **尸潮突袭**：当附近尸兄数量达到临界值时触发有组织攻击

#### 🧬 变异研究
- **样本收集**：击杀不同变种尸兄获取特殊材料
- **器官移植**：利用尸兄器官强化自身能力
- **功法修炼**：寻找并修炼特殊功法物品

#### 👑 龙右挑战
- **前置条件**：净化所有感染源或进化至顶级
- **战斗阶段**：多阶段战斗，每阶段解锁新机制
- **胜利奖励**：获取顶级材料和专属装备
