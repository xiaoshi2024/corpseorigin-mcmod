# ProjectileManager 使用文档

## 概述
通用飞行道具管理器，支持三种发射模式：粒子模拟、原版实体、自定义实体。

## 核心特性
**三种模式**：粒子模拟、原版实体、自定义实体
**任意实体发射**：玩家、怪物、NPC 均可使用
**智能伤害**：自动区分玩家/怪物攻击来源
**高度灵活**：支持自定义粒子、音效、命中回调


## 三种发射模式
| 模式 | 方法 | 特点 | 适用场景 |
|------|------|------|---------|
| **粒子模拟** | `createProjectile()` | 轻量级，无真实实体 | 剑气、魔法弹、能量波 |
| **原版实体** | `spawnEntityProjectile()` | 真实物理，功能完整 | 箭矢、火球、雪球、药水 |
| **自定义实体** | `spawnCustomProjectile()` | 完全自定义 | 你的特殊技能实体 |

## API 详解
### createProjectile() - 粒子模拟模式
#### 参数说明
| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `shooter` | LivingEntity | 射击者（玩家/怪物/NPC） | `player`, `zombie` |
| `startPos` | Vec3 | 起始位置坐标 | `new Vec3(x, y, z)` |
| `direction` | Vec3 | 飞行方向向量（会自动归一化） | `player.getLookAngle()` |
| `damage` | double | 伤害值 | `25.0` |
| `maxRange` | double | 最大射程（格） | `15.0` |
| `speed` | double | 飞行速度（格/tick） | `0.5-2.0` |
| `particleType` | String | 粒子类型字符串 | `"enchanted_hit"` |
| `hitboxSize` | double | 碰撞箱半径 | `1.5` |
| `hitSound` | String | 命中音效 ID（可为 null） | `"minecraft:entity.generic.explode"` |
| `onHit` | Consumer | 命中回调函数（可为 null） | `target -> target.setSecondsOnFire(5)` |
#### 支持的粒子类型
###  spawnEntityProjectile() - 原版实体模式
#### 参数说明
| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `shooter` | LivingEntity | 射击者 | `player` |
| `entityType` | EntityType | 实体类型 | `EntityType.ARROW` |
| `startPos` | Vec3 | 起始位置 | `player.getEyePosition()` |
| `direction` | Vec3 | 飞行方向 | `player.getLookAngle()` |
| `power` | double | 威力系数 | `1.0-3.0` |
| `configure` | Consumer | 配置回调（可为 null） | `entity -> {...}` |
#### 支持的实体类型、
###  spawnCustomProjectile() - 自定义实体模式
#### 参数说明
| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `shooter` | LivingEntity | 射击者 | `player` |
| `factory` | Function | 实体工厂函数 | `level -> new MoonSlashEntity(level, player)` |
| `startPos` | Vec3 | 起始位置 | `player.getEyePosition()` |
| `direction` | Vec3 | 飞行方向 | `player.getLookAngle()` |

### 示例 1：基础剑气（JS 脚本）
```javascript
function activate(player, world, data) {
    var ceng = data.getCeng();
    var finalDamage = calculateFinalDamage(25.0, ceng);
    var lookDir = player.getLookAngle();
    
    var startPos = new Packages.net.minecraft.world.phys.Vec3(
        player.getX() + lookDir.x * 2,
        player.getY() + 1.5,
        player.getZ() + lookDir.z * 2
    );
    
    var PM = Packages.com.phagens.corpseorigin.GongFU.JSskill.Factory.ProjectileManager;
    
    PM.getInstance().createProjectile(
        player,
        startPos,
        lookDir,
        finalDamage,
        15.0,
        0.8,
        "enchanted_hit",
        1.5,
        null,
        null
    );
    
    return true;
}
```

### 示例 3：发射箭矢（Java 代码
```javascript
public void shootArrow(ServerPlayer player) {
    Vec3 look = player.getLookAngle();
    Vec3 start = player.getEyePosition();
    
    ProjectileManager.getInstance().spawnEntityProjectile(
        player,
        EntityType.ARROW,
        start,
        look,
        3.0,
        entity -> {
            if (entity instanceof AbstractArrow arrow) {
                arrow.setSecondsOnFire(100);
                arrow.setCritArrow(true);
            }
        }
    );
}
```

public void shootMoonSlash(ServerPlayer player) {

# 示例 6：多重射击（JS 脚本）
```javascript
function activate(player, world, data) {
    var lookDir = player.getLookAngle();
    var startPos = player.getEyePosition();
    
    var PM = Packages.com.phagens.corpseorigin.GongFU.JSskill.Factory.ProjectileManager;
    
    for (var i = -1; i <= 1; i++) {
        var angle = i * 0.2;
        var dirX = lookDir.x * Math.cos(angle) - lookDir.z * Math.sin(angle);
        var dirZ = lookDir.x * Math.sin(angle) + lookDir.z * Math.cos(angle);
        
        var direction = new Packages.net.minecraft.world.phys.Vec3(dirX, lookDir.y, dirZ);
        
        PM.getInstance().createProjectile(
            player,
            startPos,
            direction,
            20.0,
            15.0,
            0.8,
            "enchanted_hit",
            1.5,
            null,
            null
        );
    }
    
    return true;
}
```
