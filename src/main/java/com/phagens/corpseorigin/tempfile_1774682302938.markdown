## 🏗️ 核心架构

### 主入口类

#### `CorpseOrigin.java` - 模组主类
- **功能**: 模组的服务器端和通用逻辑入口
- **职责**:
  - 注册创意模式标签页（原版物品 + 功法物品）
  - 初始化附件系统（技能、尸兄数据）
  - 注册事件处理器（死亡、技能、成就、语音）
  - 加载 JSON 资源（功法数据）
  - 管理网络包注册
  - 协调各子系统初始化顺序

#### `CorpseOriginClient.java` - 客户端入口类
- **功能**: 仅客户端逻辑
- **职责**:
  - 注册实体渲染器（七星棺、各种生物）
  - 客户端配置界面
  - 客户端初始化日志

## 📦 核心系统模块

### 1️⃣ **GongFU 系统（功法系统）**

**路径**: `src/main/java/com/phagens/corpseorigin/GongFU/`

#### 核心组件:

##### `JsonLoader/GongFaJsonLoader.java` - JSON 功法加载器
- **功能**: 从 `resources/data/gf_data/` 目录动态加载功法配置
- **机制**: 
  - 继承 `SimpleJsonResourceReloadListener`
  - 监听资源包重载事件
  - 使用 Gson 解析 JSON 为 `GongFaData` 对象
  - 单例模式管理所有功法数据
- **数据字段**:
  - `type_id`: 功法类型标识
  - `name`: 功法名称
  - `rarity`: 稀有度（1-5）
  - `ceng`: 层数（如"copy_1"）
  - `attributes`: 属性加成 Map
  - `skills`: 技能列表
  - `cooldown`: 冷却时间

##### `GongFaZL/` - 功法资料包
- **`BaseGongFaItem.java`**: 功法物品基础类
- **`GongFaData.java`**: 功法数据结构
- **`GongFaSkillManager.java`**: 功法技能管理器

##### `JSskill/JSSkillEngine.java` - JavaScript 技能引擎
- **功能**: 动态执行 JavaScript 脚本实现技能效果
- **特点**: 
  - 支持无参数 JS 脚本
  - 与 JSON 配置兼容
  - 灵活扩展技能逻辑

##### `PackGongFu/NetworkPaketGL.java` - 功法网络包
- **功能**: 同步功法容器数据到客户端

##### `MenuTypeRegister.java` - 菜单类型注册
- **功能**: 注册功法相关的 GUI 菜单

##### `Sceen/` - 屏幕界面
- 功法相关 GUI 界面实现

### 4️⃣ **事件处理系统**

**路径**: `src/main/java/com/phagens/corpseorigin/event/`

#### 核心事件处理器:

##### `PlayerCorpseEventHandler.java` - 尸兄玩家事件（547 行）
- **功能**: 
  - **属性修改**: +4 护甲、+3 攻击、+20% 速度、+10 最大生命
  - **吞噬机制**: 攻击活物恢复 1.5 生命值 +8 饥饿度
  - **进化系统**: 击杀生物获得进化点，提升进化等级
  - **特征获取**: 
    - 击杀鸟类 30% 概率长出翅膀（飞行）
    - 击杀鱼类 30% 概率长出鱼尾（水下加速）
  - **被动恢复**: 每 10 秒根据进化等级恢复生命
  - **状态效果**: 3 级力量 I，5 级力量 II，3 级夜视
  - **神志系统**: 随机说话（"好饿..."、"救我..."等）
  - **毒素免疫**: 免疫普通毒素效果

##### `ByWaterEventHandler.java` - 感染水源事件
- **功能**:
  - 检测玩家/村民接触感染水源
  - 施加中毒效果（玩家）或感染效果（村民）
  - 水源感染扩散（相邻水源同化）
  - 冷却机制：3 秒中毒冷却，0.5 秒检查间隔

##### `BucketFillEventHandler.java` - 桶填充事件
- **功能**: 处理水桶填充时的感染逻辑

##### `BucketEmptyEventHandler.java` - 桶清空事件
- **功能**: 处理水桶清空时的感染传播

##### `BottleFillEventHandler.java` - 瓶子填充事件
- **功能**: 处理药水瓶填充逻辑

##### `QiXingGuanDropHandler.java` - 七星棺掉落处理
- **功能**: 七星棺方块被破坏时的掉落物逻辑

##### `WeaponBreakEventHandler.java` - 武器破碎事件
- **功能**: 处理武器耐久耗尽时的特殊效果

##### `PointBlankGunEventHandler.java` - 近距离枪械事件
- **功能**: 处理近距离射击伤害计算

##### `ModEventBusSubscriber.java` - 模组事件总线订阅者
- **功能**: 通用事件处理

##### `player/playerDie.java` - 玩家死亡事件
- **功能**: 移除死亡玩家的附件数据

##### `custom/WeaponBreakEvent.java` - 自定义武器破碎事件

## 🎮 游戏机制详解

### 尸兄转化流程:
1. 玩家接触感染水源或被特定方式感染
2. `InfectionData` 记录感染状态
3. `ByWaterEventHandler` 施加效果
4. 玩家死亡后可能转化为尸兄
5. `CorpsePlayerAttachment` 附加尸兄数据
6. 获得尸兄能力和弱点

### 进化系统:
1. 击杀生物获得进化点
2. 普通生物：1-3 点
3. 高阶生物（末影龙、凋灵、监守者、龙右）：直接提升等级
4. 进化等级 1-5 级，对应不同能力
5. 通过技能树解锁新技能

### 功法系统:
1. 读取 JSON 配置文件
2. 创建功法物品（带 NBT 数据）
3. 玩家装备后获得属性加成
4. 激活功法技能需要冷却时间
5. 技能效果通过 JavaScript 脚本实现

### 水源感染机制:
1. 七星棺方块存储感染能量
2. 放置水源时检查相邻感染源
3. 曼哈顿距离≤1 格则同化
4. 感染水源对玩家施加中毒
5. 对村民施加感染效果（转化为尸兄）

## 🔍 关键设计模式

### 1. **单例模式**
- `SkillManager`: 技能管理器
- `GongFaJsonLoader`: 功法加载器

### 2. **观察者模式**
- 事件系统（@EventBusSubscriber）
- 网络包同步

### 3. **工厂模式**
- `GongFaDataFactory`: 功法数据工厂
- `SkillHandler.getOrCreate()`: 技能处理器创建

### 4. **策略模式**
- JavaScript 技能脚本动态执行
- 可替换的技能效果实现

### 5. **附件系统**
- NeoForge 的 `IAttachedData` 机制
- 用于玩家/实体数据持久化
